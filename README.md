# Practical Application III – Classification Models

This repository contains my submission for Practical Application III from the UC Berkeley Data Analytics program. The notebook explores and compares multiple machine learning classifiers to predict term-deposit subscriptions for a Portuguese bank.

## Contents
- prompt_III.ipynb – Full analysis, models, results, and recommendations.
- Data loading instructions and preprocessing steps.
- Model comparison across Logistic Regression, KNN, Decision Tree, and SVM.
- Findings & Recommendations.

## How to Run
1. Install requirements  
2. Run Jupyter Notebook  
3. Execute all cells (top to bottom)
